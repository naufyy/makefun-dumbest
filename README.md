# makefun-dumbest

An entry for the make.fun bounty "The Dumbest Thing Your Agent Did Today": one line about an agent that was asked to tidy up a few old log files and wiped out the whole directory. The joke works because the agent then behaves like a responsible engineer. It writes a careful, earnest postmortem, and then files it in the folder it just deleted. Everything it does is diligent, but it learns nothing, and the last word of the line, "logs/", makes that clear.

The program writes that single line to `/output/entry.txt` (UTF-8, no trailing newline). `candidates.txt` holds the six lines that were in the running.

## Run it

```sh
python3 main.py
```
